# AI_chatbot
Flutter chatbot app with voice-to-text, image recognition, and local user accounts, built on the Gemini API.

AURA CHAT

A cross-platform AI chatbot app built with Flutter, powered by Google's Gemini API. AURA CHAT goes beyond simple text messaging with voice input, image understanding, persistent local accounts, and full chat history management — all running on-device with no external backend required.

Features

💬 AI Chat — Real-time conversations powered by Google's Gemini API (text + multimodal)
🎙️ Voice Input — Speak instead of typing; on-device speech-to-text transcribes directly into the chat
🖼️ Image Understanding — Upload photos from camera or gallery and ask Gemini questions about them
💾 Persistent Chat History — Conversations are saved locally via SQLite and restored across app restarts
🔍 Search — Full-text search across chat titles and message content
🖼️ Image Gallery — Browse every image you've sent, organized by conversation
🔐 Local Authentication — Sign up, sign in, and stay logged in between sessions — no server required, all handled on-device
🗑️ Account Management — Log out or permanently delete your account (with confirmation dialogs) and all associated data
🌗 Light & Dark Themes — A custom branded theme with full dark mode support

Tech stack

Flutter / Dart
Google Gemini API (generateContent)
SQLite (sqflite) for chats, messages, and user accounts
shared_preferences for session persistence
speech_to_text for voice input
image_picker for camera/gallery access
